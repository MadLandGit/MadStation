Original launcher inside the renderer

Legacy is not a standalone homepage file: it is the #launcherScreen branch of src/renderer.html. This preview therefore loads the full renderer document. Opening this HTML directly in a browser may leave host-API-backed controls incomplete; use Mad Station/Electron and Developer Options for faithful interaction testing.

Source of truth: src/renderer.html, src/styles.css, src/home.css, and src/pages.css.

Review checklist

Verify that this mode remains hidden from user-facing theme pickers; it must still be available as a recovery option in the intended developer flow. Do not copy its legacy CSS conventions into a new theme—use the token/component system described in DESIGN_SYSTEM.md.
