Developer-only diagnostic kit: Default / Legacy

The original renderer homepage is not selectable in the normal Appearance picker, but it remains an internal recovery path and has a separate diagnostic kit. It is intentionally not counted among the ten built-in selectable designs in src/home-page-switcher.js.

Review all ten themes as a set after any shared token, bridge, or Appearance change.
